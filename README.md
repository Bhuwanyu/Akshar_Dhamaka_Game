# अक्षर धमाका · Akshar Dhamaka

A casual arcade game for learning to read Hindi letters: letters fall, you tap the matching key, and the cannon blasts them.

**Play:** https://bhuwanyu.github.io/Akshar_Dhamaka_Game/

Made for the Dainik Bhaskar game jam. Also on itch.io: https://bhuwanyu.itch.io/akshardhamaka
